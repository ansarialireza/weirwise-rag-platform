# Security Policy

Weirwise takes the security of our software products and user data seriously.

## Supported Versions

Only the latest release on the primary branch is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in Weirwise Platform, please report it privately:

1. **GitHub Security Advisory**: Navigate to the [Security Advisories](https://github.com/ansarialireza/weirwise-rag-platform/security/advisories) tab and click "Report a vulnerability".
2. **Email Disclosure**: If GitHub Security Advisories are unavailable, contact the project maintainers directly at `security@weirwise.local` (or via the repository owner's verified contact channel).

### What to Include in Your Report
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Potential impact and affected components.
- Any suggested mitigations or patches.

### Response Timeline
- **Initial Response**: Within 48 hours of receipt.
- **Triage & Status Update**: Within 5 business days.
- **Coordinated Disclosure**: We aim to release a patch and coordinated disclosure advisory within 30 days of confirmed verification.

Thank you for helping keep Weirwise and our users safe!
